Variables (fichier .env à la racine)
====================================

NEXT_PUBLIC_SUPABASE_URL=https://aljasquvpmcespjwnmmb.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...

Puis : node scripts/gen-config.mjs

Base de données
===============

Si les tables n’existent pas encore :
1. https://supabase.com/dashboard/project/aljasquvpmcespjwnmmb/sql/new
2. Colle supabase/schema.sql → Run

Si la table phrases existe déjà (sans colonne auteur) :
1. Même SQL Editor
2. Colle supabase/migration-auteur.sql → Run
   (Zakaria + Anyssa peuvent chacun une phrase par jour.)

Les phrases, notes et commentaires sont enregistrés pour Anyssa et toi (carnet).

Option avancée (token sbp_…) :
  set SUPABASE_ACCESS_TOKEN=sbp_...
  node scripts/apply-schema.mjs
  node scripts/apply-migration-auteur.mjs
